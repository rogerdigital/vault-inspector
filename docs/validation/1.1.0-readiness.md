Status: Released (GitHub and npm channels)

## Scope

- Unified folder and tag scan exclusions for all or selected scanners, including frontmatter and inline tags, case-insensitive matching, and descendants.
- Existing folder configurations remain compatible. Complete reference indexes protect link targets, attachment detection, and action safety.
- Per-scanner scope summaries, accurate statistical wording, configuration-aware baseline comparison, and equivalent CLI configuration plus `--exclude-tag`.
- Native settings fixes for cached definitions and hidden scanner rows.

Existing folder exclusions appear in the unified list. The first scan after upgrading may restart baseline comparison because the profile format changed; this does not mean previously detected issues were fixed. Tagged notes' attachments are not automatically excluded.
